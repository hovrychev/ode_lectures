# Обыкновенные дифференциальные уравнения

Курс из 15 лекций: от построения моделей и задачи Коши к фазовым портретам, устойчивости и бифуркациям. Рабочий формат — 15 занятий по 90 минут с отдельными практическими занятиями. Подробное содержание, условия теорем и распределение доказательств приведены в [плане курса](plan.md).

Оформление согласовано с соседним курсом `probability-theory-lectures`: Beamer, формат 16:9, тема Madrid, русский язык, определения и предупреждения в блоках, рисунки TikZ. Лектор — Ховрычев Андрей Александрович, ФИИТ, УрФУ. На титульных слайдах указаны полное имя и подразделение, в нижнем колонтитуле — «Ховрычев А. А. (УрФУ)».

## Сборка

Исходник самодостаточен и открывается во встроенном LaTeX-редакторе Codex. Для XeLaTeX/Tectonic предусмотрены шрифты Computer Modern Unicode; для pdfLaTeX сохраняется оформление T2A, как в курсе теории вероятностей. Для локальной сборки нужен pdfLaTeX с Beamer, TikZ, русским Babel и шрифтами T2A:

```sh
cd lecture1
pdflatex -interaction=nonstopmode -halt-on-error lecture1.tex
pdflatex -interaction=nonstopmode -halt-on-error lecture1.tex
```

Методические ориентиры и ссылки на MIT OpenCourseWare приведены в конце плана. Материалы написаны для этого курса; это не перевод конспектов MIT.
Для сборки второй лекции аналогично используйте каталог `lecture2` и файл `lecture2.tex`.
